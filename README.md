# Roll Craft

## Description
**Roll Craft** is an interactive browser game built with React + TypeScript using `framer-motion` for animations.  
Players flip cards to reveal different outcomes: cash, multipliers, zero, bomb, or stop — each affecting the score and the flow of the game.  
It’s designed as a quick, fun, gamified experience.

## Demo
[Play Now](roll-craft-game-henna.vercel.app)

## Tech Stack
- **React + TypeScript** — UI and logic
- **Framer Motion** — smooth animations
- **Tailwind CSS** — styling utilities
- **Vite** — fast development and build tool

## Installation
```bash
git clone https://github.com/regmysss/roll-craft-game.git
cd roll-craft-game
npm install
npm run dev
```
